What is SVM?

A Support Vector Machine (SVM) is a supervised machine learning algorithm used for classification and regression tasks. It finds the optimal hyperplane that best separates data points of different classes in a high-dimensional space.

The RBF (Radial Basis Function) kernel allows the SVM to classify data that is not linearly separable by mapping it into a higher-dimensional space where a hyperplane can separate the classes.

Understanding the Metrics

Accuracy

Fraction of all test samples the model classified correctly. Accuracy = (TP + TN) / Total

Precision

Of all samples predicted as class X, how many actually are X? High precision means few false positives.

Recall

Of all actual class X samples, how many did the model correctly identify? High recall means few false negatives.

F1-Score

Harmonic mean of Precision and Recall. Best when both are equally important. F1 = 2 × (P × R) / (P + R)

Macro Average

Computes the metric for each class independently, then takes the unweighted average across all classes.

Confusion Matrix

A 10×10 table showing how often each actual digit was predicted as each possible digit. Diagonal = correct.

About This Project

Understanding the AI/ML workflow behind handwritten digit recognition

Problem Statement

Recognise handwritten digits from 0 to 9 using machine learning, and expose the recognition capability through an interactive web application that allows users to draw digits and receive instant predictions.

Algorithm: SVM with RBF Kernel

A Support Vector Machine finds a decision boundary (hyperplane) that maximises the margin between classes. The Radial Basis Function (RBF) kernel maps data into infinite-dimensional space, enabling the SVM to classify non-linearly separable patterns like handwritten digits.

Why RBF? Digit pixel patterns are highly non-linear and context-dependent. The RBF kernel handles this complexity better than a linear kernel, while remaining computationally feasible on a small dataset.

Dataset

The project uses sklearn.datasets.load_digits() — 1,797 grayscale images of handwritten digits (0–9) written by different people. Each image is 8×8 pixels with intensity values 0–16. The data is already flattened into 64 numerical features per image.

Why train/test split? The 80/20 split ensures the model is evaluated on data it has never seen during training, giving an honest estimate of real-world performance.

Preprocessing

  • Flattening: 8×8 image → 64-element feature vector
  • StandardScaler: Transforms each feature to zero mean and unit variance; fitted only on training data
  • Pipeline: Scaler + SVC combined to prevent data leakage during cross-validation
  • Canvas inversion: White background / black ink → inverted so high pixel = more ink, matching training data polarity
  • Crop & resize: The drawn region is cropped, aspect-ratio preserved, padded, then resized to 8×8
  • Intensity scaling: Mapped from 0–255 grayscale to 0–16 dataset range

Evaluation Metrics

  • Accuracy: Correct predictions / total predictions
  • Precision: True positives / (true positives + false positives)
  • Recall: True positives / (true positives + false negatives)
  • F1-Score: Harmonic mean of Precision and Recall
  • Confusion Matrix: 10×10 table of actual vs. predicted counts

Applications

  • Reading handwritten numbers on bank cheques
  • Postal code recognition for mail sorting
  • Form digitisation in government and healthcare
  • Educational tools for learning AI/ML concepts
  • Digit entry automation in data collection
  • OCR (Optical Character Recognition) pre-processing

Limitations

  • The model is trained on 8×8 pixel images. Browser drawings are far higher resolution and must be downscaled, which can lose fine detail.
  • Writing style, stroke thickness, and digit positioning differ between the training dataset and browser drawings, causing some misclassifications.
  • The SVM does not output true probabilities by default. Decision scores are shown instead, which indicate class preference but are not calibrated probabilities.
  • The dataset is relatively small (1,797 images). Deep learning models trained on millions of images (e.g., MNIST + CNN) would significantly outperform this SVM on browser-drawn input.

Viva Questions & Answers

Q1: What is a Support Vector Machine?

A supervised ML algorithm that finds the optimal separating hyperplane with maximum margin between classes. Points closest to the boundary are called support vectors.

Q2: What is the RBF kernel and why use it?

The Radial Basis Function kernel measures similarity between points using a Gaussian function. It handles non-linearly separable data by implicitly mapping to higher dimensions, which is needed for digit pixel patterns.

Q3: What does the parameter C control?

C is the regularisation parameter. A higher C means the model tries harder to classify all training samples correctly (lower bias, higher variance). C=10 is a moderate value that allows some misclassification to improve generalisation.

Q4: Why do we scale features with StandardScaler?

SVM with RBF kernel is distance-based. Features on different scales would disproportionately influence distance calculations. Scaling ensures each pixel contributes equally to the decision boundary.

Q5: What is a Pipeline and why use it?

A Scikit-learn Pipeline chains preprocessing and model steps. This prevents data leakage: the scaler is fitted only on training data and the same transformation is automatically applied during prediction.

Q6: What is the difference between training and test sets?

The model learns only from training data. The test set is held out and used only for final evaluation, giving an unbiased estimate of how the model will perform on new, unseen data.

Q7: What does the confusion matrix show?

A 10×10 table where entry [i][j] is the number of actual class-i samples predicted as class j. The diagonal shows correct predictions; off-diagonal entries show misclassifications.

Q8: Why are SVM scores not probabilities?

SVM decision scores indicate the signed distance from the decision boundary, not calibrated probabilities. To get probabilities, Platt scaling or similar calibration is needed, which requires additional training.

Q9: How is the canvas drawing converted to model input?

The drawn region is cropped, resized to 8×8 while preserving aspect ratio, padded, grayscale-inverted (white bg → dark bg), and scaled to 0–16 intensity range to match the training dataset format.

Q10: What are the limitations of this approach?

Training images are only 8×8 pixels, so fine strokes are lost after downscaling. Drawing style differences cause some errors. Deep learning models (CNN on MNIST) would handle higher-resolution inputs far better.
